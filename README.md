## Zero-PHI Safe Input Checklist
Before expanding shorthand in any clinical utility, strip all 18 HIPAA Safe Harbor identifiers:
- Never include patient names, DOB, MRN, street address, or phone numbers.
- Use age/sex + chief complaint shorthand (`"62M HTN f/u, BP 134/82, cont lisinopril 20mg"`).
